# Bug audit — 2026-09-04

## Scope and safety

Reviewed the current working tree, including existing uncommitted work. Changes were
made locally only. No GitHub publishing, deployment, production build, running-service
restart, or live provider call was performed. Tests used temporary databases, temporary
uploads, mocked network/process boundaries, and synthetic images. Existing user changes
were preserved.

This report records confirmed defects repaired during this pass, not a guarantee that
the entire application is defect-free.

## Confirmed fixes

| Area | Defects repaired | Main implementation |
| --- | --- | --- |
| Remote downloads | Image downloads bypassed URL validation; page redirects could reach private hosts. Every hop is checked, with validated numeric destinations pinned at the transport while retaining HTTP Host and TLS hostname verification. Environment proxies cannot bypass these checks. | Backup restore | Foreign identifiers/references and filenames could cross ownership boundaries. Invalid archives or database failures could overwrite files before rollback. Restore now validates the complete imported graph, bounds archive processing, stages and checks file contents, and restores previous bytes on exceptions. ## Boundaries and remaining operational limits

- Changes are **not deployed**. The running application and existing production assets
  were not replaced. No production or real-provider end-to-end verification was done.
- DNS/TLS transport tests use fake TCP/TLS boundaries with the installed HTTPX/httpcore.
  They verify destination and hostname arguments, not actual OS routing or certificate
  handshakes. The first validated public address is selected; no hostname fallback is used.
- Backup rollback is exception-safe, not crash-atomic across SQLite and the filesystem.
  Restore serialization and replay-generation ownership are process-local.
- Replay disk mirroring is best-effort, not a durable transactional log.
- ORM transcript writes invalidate versions. Direct SQL writes bypassing the listeners
  must explicitly update the parent version stamp.
- Session JSON export/import does not carry attachment bytes; use a full-system backup
  for file restoration.
- Offline script tests do not prove live Windows process discovery or exit-code behavior.
  Force-killing the supervisor does not execute its cleanup block. Active output logs
  and the supervisor event log remain unbounded; inactive output cleanup is documented
  separately in the local operations guide.
- Production same-origin configuration assumes no later nonempty dotenv override of
  `VITE_API_BASE`. Existing bundles were deliberately not rebuilt.
